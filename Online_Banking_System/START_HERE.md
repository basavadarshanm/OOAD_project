        └─→ TransactionRepository.java

## 💾 Database Schema

```sql
users (simple user data)
├── id
├── username (unique)
├── password
├── email
└── name

accounts (bank accounts)
├── id
├── user_id (FK)
├── account_number
└── balance

transactions (history)
├── id
├── account_id (FK)
├── type (DEPOSIT/WITHDRAW/TRANSFER)
├── amount
├── description
└── date (auto)
```

**Auto-created on first run in: `./banking.db`**
